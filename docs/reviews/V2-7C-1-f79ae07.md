## Source and behavior

The feature implements the approved surface: a real first saved slide above
existing card metadata/actions, with a labeled preview that opens the same
project. Blank, loading and unavailable states retain the preview footprint.
It does not introduce a thumbnail document, persistent image cache, renderer,
schema, asset lifecycle or authored layout. The headless projection uses the
canonical owner/admin/local store read, refuses revision mismatch and returns
only identity/revision/first scene. The thin authenticated route sets private
no-store responses and applies the existing access policy. The 2MiB cover limit
is applied in UTF-8; list metadata remains small. The server still loads the
complete document through the existing store primitive, as disclosed.

The browser validates the scene, gates fonts and uses the shared `sceneToSvg`
projection. The fixed 16:9 region preserves slide proportions through SVG's
viewBox. The workspace owns a near-visible two-job queue, cancellation and
15-second deadline, with a disposable 24-entry/8MiB revision cache. Offscreen
and departed consumers unsubscribe. Post-await abort/session checks prevent
abandoned rendering or publication. Session invalidation clears cards and
focuses reload guidance; same-document checks are bounded by a one-second timer,
focus/visibility checks and a synchronous action guard. Actual account changes
also remount the workspace by account identity.

All earlier review findings were corrected before acceptance: StrictMode loader
lifetime, settled same-document identity changes, permanent failed font promises,
and rendering resumed after cancellation. A real dynamic font request failure
then established that evicting the promise alone did not reset Chrome's failed
FontFace. A separate static WOFF2+WOFF outage established the corresponding static
case. The final source removes only matching failed injected sheets, protects
replacements by sheet identity, and recreates matching failed static CSS rules
with their original source, weight/style and unicode subset. Successful distinct
faces remain in place. Existing font-coverage vocabulary was not expanded.

I found no remaining blocking source defect or scope expansion. Existing engine,
compiler, ownership/regeneration, revision history and native document authority
remain unchanged. List consolidation, toolbar changes, Fit and the earlier
restore-timeout investigation remain outside this slice.
