## Result and preservation

An owner-only headless facade qualifies the complete saved scene/catalog snapshot
under one canonical read lock, validates every citation/anchor/optional UTF-8 range,
then releases the lock before native generation. Missing/stale/foreign/corrupt,
ambiguous/orphaned/changed/hidden or system-chrome targets refuse completely.
Visible ordinary locks remain exportable. Referenced bodies read in24-item pages;
full catalog accounting and existing512-source/4MiB limits are retained.

The shared renderer lifts only the citation refusal for an internal single-use
qualified snapshot. Portable native Selection Pane labels, complete quoted source
titles/full URLs and a claim-support-not-assessed notice enter speaker notes.
Control/bidi characters are reversibly escaped; no appended engine/project/source/
citation IDs, excerpts, provider/anchor/range fields or notes hyperlinks are added.
Actual slide/object/notes OOXML relationships and text are verified before returning
bytes. Existing raw, file and saved GET paths still refuse cited scenes.

The CLI requires explicit consent for each cited export, binds its token once,
never retries stale snapshots and has no admin private-source override. Uncited
output remains usable without consent. Owned0700 temporary directories/0600 files
are flushed/closed, then published by exclusive hard link. Existing targets and
symlinks are never replaced. Shutdown/publication failures are sanitized; a failed
acknowledgement after publication reports an unknown complete-file outcome.
No scene, history, source, chat or provider authority changes; no public UI/endpoint.
