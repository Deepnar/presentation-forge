## Inspected facts

The existing exact-owner citation-read wrappers provide one canonical saved
document/catalog lock without a save hook. J2's bounded reader already supplies
catalog accounting and selected canonical bodies; J4 supplies target indexing,
content anchors and snippet-relative range observation. The new exporter can
capture strict immutable binding/counter/disclosure input, qualify all references
in one transaction and then release the lock before generation. Earlier inspection
or supplied counters are no permission; every export must re-enter current owner
authority. A clear/save/delete winning first refuses stale counters, while a
qualified captured snapshot is intentionally independent after release.

Target existence, content equality, retained identity and range validity remain
separate from claim support. J4's `blocked` observation combines ordinary locks,
hidden content and chrome, so the exporter cannot reuse that flag as a visibility
test. The final contract distinguishes these rules, permits visible ordinary locked
objects and refuses missing/ambiguous/changed/hidden/invalid-range associations
without silently dropping them. Export changes no scenes, commands/history/undo,
source state or retention preference.

Installed PptxGenJS4.0.1 has `addNotes(string)` and per-primitive `objectName` support.
Its notes generator serializes a notes text body, with fixed notes-master geometry;
its presence does not demonstrate long printed-page fit. Existing renderer draw
order and group traversal can produce deterministic portable names. A group is
flattened into child emissions; the missing-image placeholder can emit both a
shape and text. A one-to-one engine-ID/native-ID assumption would be wrong.
`uniquePptxShapeIds` may renumber native IDs, so the plan correctly requires trace
verification against actual post-normalization slide/object names and notes
relationships before publishing bytes. It adds no persistent source mapping or
private identifiers to the archive.

The proposed dependency direction is feasible: trusted src assembly supplies a
canonical qualifier callback to a renderer-owned factory. The renderer owns its
private issuer/map, consumes prepared authority before asynchronous generation and
returns no issuer/handle/callback access through the facade. Scene/projection types
and callbacks suffice; SQL/auth/src imports into rendering and cycles are not
needed. This protects external JSON/raw caller boundaries, not arbitrary trusted
Node execution. Ordinary preflight/direct/file/current GET paths remain closed
for cited scenes; only the qualified exact snapshot may lift that single refusal.

## Material findings resolved in the final delta

- **Notes fit:** resource caps do not establish printable fit. The contract now
  preserves bounded complete Notes text while explicitly allowing long printed
  notes to overflow; it promises no shrinking, truncation or pagination. One short
  representative native notes-page visual and long-case exact text/limit evidence
  are separate obligations. Printable design stays in the roadmap.
- **Asset scope:** the existing renderer delegates authored image/background paths
  to PptxGenJS. The final wording prohibits source/page/notes-URL fetching and new
  fetch grants while retaining that inherited asset policy. Embedded fixtures and
  no real network calls keep validation bounded; this is no new SSRF qualification
  or incidental asset-hardening implementation.
- **Private file publication:** the current generic file adapter simply writes a
  path and is not sufficient for the new private publication promise. The new CLI
  must use verified0700/0600 owned temporary resources, flush/close complete bytes,
  then exclusively hard-link on the same local POSIX filesystem. Existing targets
  and races cannot be replaced, and unsupported publication refuses rather than
  falling back to an overwrite or partial final file. Unknown acknowledgement
  remains an unknown complete-file outcome.
- **Group scope:** J4 content anchors exclude system-chrome subtrees. Group source
  mapping now excludes those same subtrees while chrome still renders, preventing
  attribution to emitted furniture outside the anchored authored scope.
- **Prepared authority:** issuer/map ownership, callback-only src dependency and
  pre-generation single-use consumption are pinned, including consumption on
  failure. Raw renderer options and JSON cannot mint a reusable bypass.
- **Allowlist and literal data:** forbidding all identifier substrings would
  contradict full title/URL preservation. The final rule permits those approved
  field values, even private query/identifier strings, but appends no Forge
  identity/provenance/hash/range/excerpt fields. Quoted reversible literal encoding
  visibly escapes controls, line separators and bidi-formatting characters before
  XML escaping. Malformed surrogates refuse; labels are never parsed from field
  data. The human must approve full query disclosure explicitly.
