Use [GitHub Discussions](https://github.com/Deepnar/presentation-forge/discussions)
for setup questions, usage help and ideas. Use an issue when there is a
reproducible problem in Presentation Forge.

When asking for help, include the release or commit, operating system,
installation mode, model route (BYOK or Ollama), relevant sanitized logs and
the exact command or screen where the problem occurred. Never post an API key,
session token, password, private research document or confidential deck.

Provider pricing, invoices, refunds, credits and account limits are controlled
by the provider and must be handled with that provider. Forge offers a token
safety guard for BYOK calls but does not issue or control the provider bill.

Security vulnerabilities must be reported privately according to
[SECURITY.md](SECURITY.md).
